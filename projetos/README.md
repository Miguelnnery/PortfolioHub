# Projetos em Python

Esta pasta contém projetos em Python

-"poo_bank" é um programa orientado ao objeto, onde simula um banco simples com PJ E PF;

-"bank2" é um exemplo do funcionamento do "poo_bank";

-"calculadora" é uma calculadora simples;

-"cursoonline" é um programa orientado a objeto de cursos online;

-"domino com repeticao" exercício lógicos com ênfase em repetição;

-"domino sem repeticao" exercício lógico

-"loja_gamer" é um programa orientado ao objeto, onde simula uma loja de períféricos.

-"volume da esfera" programa que calcula o volume de uma esfera
